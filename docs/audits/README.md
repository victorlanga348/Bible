# Auditorias

[Segurança](security.md) e [acessibilidade](accessibility.md) contêm planos de verificação, não certificações ou auditorias executadas.
Não há aplicação para auditar nesta etapa. Registar evidências, achados e decisões quando os respetivos fluxos existirem.
A validação documental inicial está em [DOC-0001](../tasks/DOC-0001-inicializacao-governanca.md).
