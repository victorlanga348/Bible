# Padrões aprovados

Estado inicial: nenhum padrão de implementação com exemplo real aprovado.
Usar [Approved Pattern](../templates/approved-pattern.md) e nomes `PATTERN-0001-descricao-curta.md`.

Um padrão exige contexto, critérios de utilização, limites, exemplo existente no repositório, testes e aprovação identificada.
DDD e arquitetura hexagonal são direções já definidas; isso não constitui evidência de um padrão de implementação concreto.
Manter índice de estado, aprovador e exemplos quando forem criados registos.
