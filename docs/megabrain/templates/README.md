# Templates do MegaBrain

- [Error Report](error-report.md): erro reproduzível e regressão.
- [Lesson Learned](lesson-learned.md): aprendizagem reutilizável.
- [Approved Pattern](approved-pattern.md): padrão com exemplo real e aprovação.
- [Technical Investigation](technical-investigation.md): pergunta, hipóteses e evidências.

Copiar para a categoria adequada, atribuir ID e substituir instruções por factos. Campos sem informação devem indicar «pendente», «não conhecido» ou «não aplicável» com motivo.
Um template não representa incidente ocorrido, padrão aprovado ou investigação executada.
