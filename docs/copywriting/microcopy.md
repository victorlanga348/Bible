# Microcopy

Estado: exemplos propostos; não são respostas reais, fontes verificadas ou texto final aprovado.

## Princípios
Português claro, respeitoso e preciso. Indicar o problema, o efeito no estudo e uma ação disponível quando existir.
Evitar linguagem de autoridade absoluta, consenso presumido ou confirmação de persistência sem evidência.

| Situação | Texto proposto |
|---|---|
| Antes da seleção | Selecione uma passagem para começar o estudo. |
| Estudo em preparação | A preparar o estudo e a consultar as fontes disponíveis. |
| Biblioteca insuficiente | Não foram encontradas fontes suficientes na biblioteca disponível para sustentar esta afirmação. |
| Falha na consulta | Não foi possível consultar as fontes. Esta falha não permite concluir que não existem evidências. |
| Hipótese | Esta explicação é uma hipótese; a evidência disponível é limitada. |
| Divergência | Existem interpretações diferentes desta passagem. Consulte os fundamentos e os limites de cada leitura. |
| Referência não validada | Não foi possível verificar esta referência. |
| Histórico vazio | Ainda não há estudos guardados para consultar. |
| Falha ao guardar | Não foi possível guardar o estudo. |
| Continuação | Que questão gostaria de aprofundar nesta passagem? |

Usar cada mensagem apenas quando o estado correspondente estiver confirmado. Não prometer recuperação, gravação automática ou nova tentativa se essa capacidade não estiver implementada.
